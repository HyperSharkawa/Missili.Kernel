# 第二阶段交付审阅

本阶段实现 OneBot v11 接入、可扩展消息与事件存储、后台归档以及独立协议 Mock。代码基于 `df668aec60dbc4a2b6781abf740c5f5e90b9bbad`，当前交付保留为工作区变更。

## 主要变更

- 官方适配器是可回收编译插件，Host 发布包包含 `plugins/onebot`，默认不启用。
- 正向和反向 WebSocket 均支持 Universal 与 API／Event 分离布局。反向入口固定为 `/adapters/{adapterId}/ws`。
- 消息段使用稳定字符串类型与版本化 JSON；多媒体和结构化内容使用关系引用。业务事件独立保存并向插件开放。
- 原件导入、标准媒体查询、显式路径映射与转发归档共用宿主生命周期；归档恢复不重放聊天业务。
- 发送保留意图、未知结果、异步受理、迟到确认和自身消息合并；未知结果不重发。
- 插件契约升为 2，清单格式仍为 1。现有示例和测试夹具同步重新编译。
- 新迁移保留旧消息、媒体、转述和排序。仅在旧模型能够完整表达现有数据时允许降级。
